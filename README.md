#  CampusAI

CampusAI is an AI-powered Student Success and Career Intelligence Platform that helps students analyze their academic performance, identify skill gaps, and receive personalized career recommendations using Machine Learning and Artificial Intelligence.

---

##  Features

###  Authentication & Security
- JWT Authentication
- Password Hashing
- Protected APIs
- User Authorization
- Ownership-Based Access Control

###  Student Profile
- Create Student Profile
- Update Student Profile
- View Public Student Profiles

###  Academic Records
- Add Academic Records
- Update Academic Records
- Delete Academic Records
- View Academic History

###  Skills Management
- Add Skills
- Update Skills
- View Student Skills

###  Projects
- Add Projects
- Update Projects
- Delete Projects
- View Student Projects

###  Career Goals
- Add Career Goals
- Update Career Goals
- Delete Career Goals
- View Career Goals

###  Backend Features
- FastAPI REST APIs
- SQLAlchemy ORM
- PostgreSQL Database
- Pydantic Validation
- Global Exception Handling
- Centralized Logging
- Production-ready Project Structure

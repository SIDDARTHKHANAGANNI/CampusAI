# CampusAI

CampusAI is an AI-powered Student Success and Career Intelligence Platform designed to help students understand their academic performance, identify career skill gaps, and receive personalized learning recommendations.

## Core Features

- Academic Performance Prediction
- At-Risk Student Detection
- Explainable AI using SHAP
- Career Readiness Analysis
- Skill-Gap Analysis
- Personalized Learning Roadmaps
- Resume-Job Matching
- AI Student Copilot using RAG
- Student Analytics Dashboard
